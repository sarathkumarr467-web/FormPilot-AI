# FormPilot AI — Understand. Fill. Verify. Apply.

An AI-powered application assistance platform that helps students, job seekers, scholarship applicants, and government-scheme applicants understand forms, complete applications, verify information, and track application progress.

## Overview

FormPilot AI simplifies confusing application processes through bilingual guidance, intelligent document analysis, form-filling assistance, eligibility checks, and application tracking.

### Key Features

- **Form Understanding:** Explains form fields, required information, expected formats, and examples in English and Tamil.
- **Form Filling Assistant:** Supports guided form completion, profile-based autofill, validation, and PDF export.
- **Filled Form Verification:** Checks formatting, missing information, and potential inconsistencies across documents.
- **Application Guide:** Organizes application steps, deadlines, fees, eligibility details, and official links from available source documents.
- **Eligibility Checker:** Compares applicant details with configured scheme rules such as income, age, category, and academic criteria.
- **Document Center:** Organizes supporting documents and helps identify missing or expired documents.
- **Application Tracker:** Tracks application status, progress, deadlines, reminders, and checklists.
- **Document Classification:** Uses a trained machine-learning model to classify documents into six application-related categories.
- **AI Assistant:** Provides context-aware assistance in English and Tamil.
- **Dashboard and History:** Displays application/document activity and maintains analysis history.

## Technology Stack

### Frontend
- Next.js / React 18
- TypeScript
- Tailwind CSS
- Lucide Icons
- Chart.js
- English and Tamil language support
- Light and dark themes

### Backend
- FastAPI
- REST API
- Document parsing for PDF, DOCX, TXT, images, CSV, and XLSX
- ReportLab PDF generation

### Machine Learning
- Text preprocessing with Unicode NFKC normalization
- TF-IDF feature extraction with 1–2 n-grams and up to 2,500 features
- Calibrated LinearSVC classifier
- Stratified 3-fold cross-validation

### Database and Authentication
- SQLite for local development
- Supabase PostgreSQL for cloud deployment
- Row Level Security (RLS)
- Email/password authentication and Google OAuth configuration

## Machine Learning Model

The document classifier supports six categories:

- `scholarship_form`
- `college_admission`
- `job_application`
- `internship_application`
- `government_scheme`
- `supporting_document`
